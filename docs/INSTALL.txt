OCXBar — OpenCodex 사용량을 macOS 메뉴바에 보여주는 앱

필요한 것
- Apple Silicon(M1 이상) Mac, macOS 13 이상
- 이 Mac에서 OpenCodex(ocx)가 실행 중이어야 함 (터미널에서 ocx status 로 확인)
  관리자 토큰은 ~/.opencodex/admin-api-token 을 자동으로 읽어서 따로 설정할 필요 없음

설치
1. OCXBar.app 을 "응용 프로그램" 폴더로 옮깁니다.
2. Apple 공증을 받지 않은 앱이라 처음 한 번은 그냥 열면 막힙니다. 둘 중 하나로 여세요.
   - 터미널:  xattr -dr com.apple.quarantine /Applications/OCXBar.app  입력 후 더블클릭
   - 또는 더블클릭 → 막히면 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기"
3. 메뉴바에 "OCX 94%" 또는 "CX 99% · CL 67%" 같은 표시가 나타나면 성공입니다.
   메뉴바가 꽉 차 있으면 노치 뒤에 가려질 수 있어요. 다른 아이콘을 줄여 주세요.

사용
- 클릭하면 계정별 5h / Weekly 남은 양, 리셋 시간, 현재 사용 중(ACTIVE) 계정을 보여줍니다.
- 60초마다 자동 갱신되고, Refresh 버튼은 바로 새로 조회합니다.
- 톱니바퀴: 서버 주소(기본 http://127.0.0.1:10100), 메뉴바에 보일 제공자, 로그인 시 자동 실행.

문제 해결
- "OCX --" 이면 OpenCodex가 꺼져 있거나 주소/토큰이 맞지 않는 것입니다. 창에 이유가 표시됩니다.
- 종료: 메뉴 창 오른쪽 아래 전원 버튼.
